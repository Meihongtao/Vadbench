# Vadbench 实验结果汇总

评测引擎：`webrtc` / `silero` / `funasr_fsmn` / `firered` / `pyannote`  
质量指标：10 ms 帧级 **F1 / P / R / FAR / Miss**（时长加权）；GT = 说话人活动并集。  
性能指标：ONNXRuntime 端到端延迟（特征+推理+后处理成段），不含模型加载。

原始表：`results/summary_*.csv`、`results/perf_*.csv`。

## 0. 指标怎么算

### 0.1 段 → 帧

1. 参考标注：各说话人时间段**取并集** → speech / non-speech。
2. 预测段与参考段均按 **10 ms** 栅格化为二值帧序列（1 = 语音，0 = 非语音）。
3. 逐帧对比得到混淆计数：

| 符号 | 条件 | 含义 |
|------|------|------|
| TP | 参考=1 且 预测=1 | 正确检出的语音帧 |
| FP | 参考=0 且 预测=1 | 把非语音判成语音 |
| TN | 参考=0 且 预测=0 | 正确的非语音帧 |
| FN | 参考=1 且 预测=0 | 漏检的语音帧 |

实现：`vadbench/eval/rasterize.py`、`vadbench/eval/metrics.py`。

### 0.2 单文件公式

与代码一致（分母为 0 时该指标记 0）：

```text
P     = TP / (TP + FP)          # Precision：预测为语音的帧中，真语音占比
R     = TP / (TP + FN)          # Recall：参考语音帧中，被检出占比
F1    = 2 * P * R / (P + R)     # 当 P+R=0 时 F1=0
      = 2*TP / (2*TP + FP + FN) # 与上一行等价

FAR   = FP / (FP + TN)          # False Alarm Rate = 非语音帧上的虚警率（即 FPR）
Miss  = FN / (TP + FN)          # Miss Rate = 语音帧上的漏检率（= 1 − R）
```

注意：

- **FAR** 分母是「全部非语音帧」`FP+TN`，不是 `TP+FP`。
- **Miss** 分母是「全部参考语音帧」`TP+FN`，与 **R** 互补：`Miss = 1 − R`。
- 会议音频里非语音往往较少，**FAR** 对虚警敏感；**Miss** 对漏检敏感。

### 0.3 时长加权汇总

表中主结果为**时长加权**：先把各文件的 TP、FP、TN、FN **分别求和**，再套用上式（长文件权重大）。  
CSV 中 `*_unweighted` 为各文件指标算术平均，本汇总未用。

## 5. 二次分析

上表全是汇总值。每文件分布、FAR 的分母口径这些信息在汇总里看不到，用：

```powershell
python -m vadbench.report
```

它只读取 `results/eval_*.json`，**不重新跑任何模型**，输出：

| 输出 | 内容 |
|------|------|
| 每文件 F1 分布 | 最差 / p25 / 中位数 / 均值 / 最大 / `F1 < 0.9` 的文件数 |
| FAR vs FP/N | 同一批虚警帧的两种读法，附该数据集的语音帧占比 |
| 跨数据集透视 | 引擎 × 数据集的时长加权指标矩阵，标出每列最优 |

结果写到 `results/report/`。

汇总口径的坑：换一种聚合方式排名就会变。AliMeeting test 上 silero 与 webrtc
在时长加权下 silero 领先 0.9 个点，文件平均下 webrtc 反超 0.2 个点，中位数下
silero 又领先 1.3 个点 —— 因为 silero 有一个文件 F1 只有 0.074，
文件平均被这个离群值拖死，而时长加权把它稀释掉了。

FAR 的坑：会议音频里语音帧占 80%~92%，非语音帧是少数派，分母一小 FAR 就被
放大。RAMC 上 funasr_fsmn 的 FAR = 0.600 听起来像「六成时间在乱报」，实际
`FP/N` 只有 10.3%（每 10 帧有 1 帧非语音进 ASR）。建议同时报 `FP/N`，
或者只报 Precision。

同一 `(数据集, 引擎, 文件)` 有多次运行时脚本取时间戳最新的那次，所以重跑单个
引擎不需要手工维护「哪份结果才算数」。脚本还会把重算的 F1 与 `summary_*.csv`
对一遍，不一致就报警。

自测：`python tests/test_report.py`
